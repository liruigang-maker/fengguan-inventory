## 这个系统做什么

给记账人在手机上记入库、出库和回款，在手机或电脑上查库存、某个品种出了多少、客户回了多少钱。四个发货平台是通辽、包头、兰州、土右旗。没填发货平台的出库按零售/其它计算。

字段和计算规则见 [丰冠农业库存销售系统开发方案.md](丰冠农业库存销售系统开发方案.md)。

## 本机运行

需要 Node.js。

```bash
npm install
npm run dev
```

开发时页面在 http://localhost:5173 ，接口由本机 `3000` 端口提供。

已经构建过前端时，可以直接启动服务（默认 http://localhost:3000 ）：

```bash
npm run build
npm start
```

端口用环境变量 `PORT` 修改。阿里云对外使用的是 `8084`，对应启动时设置 `PORT=8084`。数据文件默认在 `data/fengguan.db`。
